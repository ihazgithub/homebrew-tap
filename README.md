# Malsah Labs Homebrew Tap

Homebrew casks for apps by Malsah Labs.

## TopOff

[TopOff](https://github.com/ihazgithub/TopOff) keeps your Homebrew packages up to date from the menu bar.

```sh
brew install --cask ihazgithub/tap/topoff
```

TopOff updates itself in place, so `brew upgrade` leaves it alone unless you pass `--greedy`.
